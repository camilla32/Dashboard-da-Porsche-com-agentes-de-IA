# 🚗 Porsche Sales Intelligence Dashboard

## 📌 Sobre o Projeto

O **Porsche Sales Intelligence Dashboard** é uma aplicação web desenvolvida para análise de dados de vendas da Porsche, permitindo a visualização de indicadores estratégicos, tendências de mercado e desempenho comercial por meio de uma interface moderna, responsiva e interativa.

O projeto foi desenvolvido com foco em **Business Intelligence (BI)** e **Data Analytics**, transformando dados brutos em informações relevantes para apoiar a tomada de decisão.

---

## 🎯 Objetivo

Desenvolver um dashboard interativo capaz de:

* Monitorar o desempenho das vendas da Porsche;
* Identificar os modelos mais vendidos;
* Analisar o comportamento das vendas por cidade;
* Avaliar o faturamento gerado;
* Identificar tendências por ano-modelo;
* Apoiar decisões estratégicas por meio de indicadores e visualizações de dados.

## 📊 Perguntas de Negócio Respondidas

### 1. Quais são os modelos Porsche mais vendidos?

Permite identificar os veículos com maior participação nas vendas e compreender a preferência dos clientes.

### 2. Qual ano-modelo apresenta maior demanda?

Avalia quais gerações de veículos possuem maior volume de comercialização.

### 3. Quais cidades concentram mais vendas?

Permite identificar regiões estratégicas para campanhas de marketing e expansão comercial.

### 4. Qual o faturamento total gerado?

Monitora a receita acumulada das vendas.

### 5. Qual o ticket médio das vendas?

Avalia o valor médio gasto pelos clientes.

---

## 📈 Principais Insights

Durante a análise dos dados foi possível identificar:

* O ano-modelo 2024 apresentou o maior volume de vendas;
* Alguns modelos da linha Porsche lideram o faturamento total;
* Determinadas cidades concentram a maior participação comercial;
* O comportamento das vendas varia conforme os filtros aplicados;
* A análise dinâmica permite identificar rapidamente oportunidades de negócio.
